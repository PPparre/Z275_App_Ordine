Z275 · Prova condivisione file

A cosa serve

Verifica se questo telefono permette a una pagina web di passare un file all'app di posta (o a WhatsApp) già allegato. Ogni riga prova un tipo di file: se compare «supportato», il tasto Condividi apre il menu di condivisione con il file allegato.

I file sono solo di prova (contenuto finto), nessun dato viene inviato da nessuna parte.

Come leggere il risultato

supportato: il file può essere allegato in automatico.
non supportato: Chrome blocca quel tipo; va allegato a mano.
non disponibile: il browser non offre la condivisione di file (apri la pagina in Chrome su Android, con HTTPS).
